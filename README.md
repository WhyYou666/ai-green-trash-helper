# 垃圾分类小助手（规则版）

一个用 Python 写的小工具：输入一种垃圾的名字，它告诉你属于哪一类，并给出投放提示。

## 为什么做这个

比赛的主题是「AI for Green」，环保是很具体、很日常的切入点。垃圾分类看起来简单，但很多人（包括我自己）经常分错。所以我先做了这个最简版本，先把「识别 -> 给建议」的完整流程跑通，之后再把它升级成真正的 AI 模型。

## 功能

- 输入垃圾名称，输出所属类别：可回收物 / 有害垃圾 / 厨余垃圾 / 其他垃圾
- 给出对应的投放提示
- 输入 q 随时退出

## 怎么用

电脑上需要先装好 Python 3。然后在文件所在目录运行：

```bash
python trash_helper.py
